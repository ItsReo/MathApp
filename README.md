# Math Function Solver

A small web app that takes a mathematical function of x as input and
computes the solution you ask for. It can also explain the solution
step by step.

Built with **Python**, **SymPy** (the math engine) and **Streamlit**
(the web interface).

## Features

- Type a function such as `x^2 + 3x - 4`, `sin(x)/x` or `e^x`
  (`^` for powers and `3x` for `3*x` both work), or pick one from the examples list.
- Choose what to do with it from a dropdown:
  - Evaluate at a point
  - Find roots (where f(x) = 0)
  - Derivative
  - Integral (indefinite)
  - Definite integral (with bounds)
  - Limit (including infinity and one-sided limits)
  - Min / max (turning points, using the second derivative test)
  - Simplify / factor / expand
  - Plot
- Or **describe it in words**, for example "find the slope",
  "area under the curve", "plot from -5 to 5" or "limit as x approaches 0".
  Numbers in the sentence are picked up automatically.
- A **Show detailed steps** toggle explains how the answer was reached.

## How to install and run

1. Install Python 3 from python.org (on Windows, tick "Add Python to PATH").
2. Open a terminal in this folder and install the libraries:

   ```
   pip install -r requirements.txt
   ```

3. Start the app:

   ```
   streamlit run app.py
   ```

   It opens in your browser (usually at http://localhost:8501).
   Press `Ctrl + C` in the terminal to stop it.

## Example inputs to try

| Function | Operation | Expected result |
|---|---|---|
| `x^2 + 3x - 4` | Find roots | x = -4 and x = 1 |
| `x*sin(x)` | Derivative | x cos(x) + sin(x) |
| `x^3 - 3x` | Min / max | max at x = -1, min at x = 1 |
| `(x^2 - 1)/(x - 1)` | Limit at 1 | 2 |
| `1/x` | Limit at 0 (both sides) | does not exist |
| `x^2` | Definite integral, 0 to 3 | 9 |

## How it works

1. **Parse:** the typed text is converted into a SymPy expression
   (`parse_function`). `parse_expr` is used instead of `eval` so that
   user input cannot run arbitrary code.
2. **Choose the operation:** from the dropdown, or by matching keywords in the
   user's sentence (`KEYWORDS` and `pick_operation`).
3. **Compute:** the matching SymPy function does the math
   (`solve`, `diff`, `integrate`, `limit`, `factor`, ...).
4. **Display:** results are shown as LaTeX. The plot uses `lambdify` to turn the
   function into a fast numeric one.
5. **Steps (optional):** the explanations are generated by the app's own code
   from the actual function (for example, naming the rule used on each term).

## Limitations

- The "describe it in words" mode matches keywords; it does not understand
  full sentences. If two keywords appear, the first one in the list wins.
- Detailed steps are a simplified explanation, not a full textbook solution.
  Complicated functions show the rule and the result but not every sub-step.
- Only one variable (x) is supported.
- Periodic functions (like sin) have infinitely many roots and turning points;
  only the ones SymPy returns are shown.
